Advanced content options
Scripts, event handlers, embedded pages, forms, and inline styles are removed. Preview execution remains isolated.

• Text should start with "Character Name:" to identify speakers (multi-word names are supported)

• Use Insert part break at cursor to divide pasted text

• You can use markdown formatting: **bold**, *italic*, ~~strikethrough~~

• For linked footnotes, place a superscript number like ¹ in the text, then end the story with **Footnotes** and a line beginning with the same number
