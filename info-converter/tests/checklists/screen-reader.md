# Lore Codex screen-reader smoke checklist

Use a sanitized or empty project. This is a short release smoke, not a full content read-through.

- [ ] The page title and current main section are announced without skipped heading levels.
- [ ] Main navigation is announced as five tabs; Left/Right, Home, and End move and select tabs.
- [ ] Project picker, icon-only actions, color/range/file controls, and their helper text have useful names and descriptions.
- [ ] Opening Character and one nested modal announces a labelled dialog and moves focus inside it.
- [ ] Tab and Shift+Tab stay inside the active dialog; Escape closes only the top dialog and returns focus to its opener.
- [ ] Preview, save, import, publish, success, and error messages are announced once with suitable urgency.
- [ ] Content categories and their item counts are understandable and operable without pointer or drag gestures.
- [ ] At 200% zoom, reading and focus order stay logical and no control becomes unreachable.
